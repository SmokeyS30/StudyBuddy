# StudyBuddy Support

StudyBuddy provides study planning, original practice questions, exam simulations, interactive labs, progress tracking, and AI-assisted tutoring for A+ Core 1 220-1201, A+ Core 2 220-1202, and Security+ SY0-701.

## Contact Support

Email: edwardbloomfield@mac.com

For faster help, include:

- Your StudyBuddy version and build from Settings > Updates
- Your selected exam
- The screen or feature where the issue occurred
- The exact error message
- A screenshot that does not contain passwords, API keys, or private information

## Common Fixes

### AI Tutor is offline

1. Confirm the device has an internet connection.
2. Open Settings in StudyBuddy.
3. Confirm the AI Tutor Server URL is `https://studybuddy-ai-server-m5zi.onrender.com`.
4. Tap Check AI Server Now.
5. If the issue continues, email support with the status message shown in the app.

### Progress or results look wrong

Confirm the correct exam is selected in Settings. StudyBuddy stores separate progress for each supported exam. Use Reset all StudyBuddy progress only when you intend to erase local progress for every exam.

### A practice question or lab has a problem

Include the exam name, question or lab title, difficulty, and a screenshot. Do not send real certification exam questions, exam dumps, passwords, or personally sensitive information.

## Privacy And Data Requests

Read the StudyBuddy Privacy Policy at `PrivacyPolicy.html`. For a question or request involving server-side study data, email edwardbloomfield@mac.com and include the Student profile code shown in StudyBuddy Settings. Reset All Progress clears study data stored on the device; contact support for a server-side learning-profile deletion request.
