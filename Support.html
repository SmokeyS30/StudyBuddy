PrepNexus: IT Certs Support

Help for iOS 3.2 (22) and Android 1.0 (1)

Contact Support

Email edwardbloomfield@mac.com.

Include the app version and build, selected exam, feature name, exact error, and a screenshot when useful. Never include passwords, API keys, or private information.

AI Tutor Is Offline

  1. Confirm the device has an internet connection.
  2. Open PrepNexus Settings.
  3. Confirm the server URL is https://studybuddy-ai-server-m5zi.onrender.com.
  4. Tap Check AI Server Now.
  5. Email support with the status message if the issue continues.

Progress Or Results Look Wrong

Confirm the correct exam is selected in Settings. PrepNexus stores separate local progress for each supported exam. Reset all PrepNexus progress only when you intend to erase local progress for every exam.

Question Or Lab Feedback

Include the exam, question or lab title, selected difficulty, and a screenshot. Do not send real certification exam questions or exam dumps.

Privacy And Data Requests

For a server-side learning-profile question or deletion request, email support and include the Student profile code shown in PrepNexus iOS Settings. Reset All Progress clears data stored on the device; it does not by itself erase the server learning profile.

Compatibility

PrepNexus requires iOS 17 or later or Android 8.0 or later. Production iOS AI requests use HTTPS and enforced Apple App Attest. Protected Android tutoring remains disabled until Google Play Integrity is configured.
